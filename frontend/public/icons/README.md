# Iconos PWA pendientes

Agregar `pwa-192x192.png` y `pwa-512x512.png` y declararlos en `manifest.icons` de `vite.config.ts` con `src`, `sizes` y `type: image/png`. Estos recursos de identidad visual se crearán al diseñar el portal. Por ahora el service worker puede cachear la interfaz, pero la instalación PWA queda pendiente de estos iconos.
